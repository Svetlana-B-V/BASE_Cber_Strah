🛡️ B. BASE: Подбери страховку (Сбер)

Решение задачи бинарной классификации для предсказания покупки страхового продукта «Защищённый смартфон».

📌 Описание задачи

Компания выводит на рынок страховку «Защищённый смартфон». Необходимо определить клиентов, которые с наибольшей вероятностью приобретут этот продукт.

Целевая переменная (accepted): 1 — клиент купил страховку, 0 — не купил.

Метрика качества: F1-score.

Данные

train.csv — обучающая выборка (6 000 строк) с целевой переменной.

public_test.csv — открытая тестовая выборка (1 000 строк) без целевой переменной.

sample_submission.csv — пример формата ответа.

Признаки включают демографические данные, занятость, банковский профиль, цифровое поведение, характеристики смартфона и маркетинговую историю.

⚙️ Установка и требования

Python: 3.8+

Основные библиотеки: pandas, numpy, scikit-learn, catboost

Установите зависимости с помощью команды:

pip install -r requirements.txt


🚀 Запуск

1. Обучение модели

Скрипт загружает данные, делит их на train/valid (80/20 со стратификацией), обучает CatBoost, выводит метрику на валидации и сохраняет модель.

python train.py


На выходе создается файл модели: catboost_model_seed_42.cbm

2. Предсказание

Скрипт загружает тестовые данные, обученную модель, генерирует предсказания и сохраняет итоговый файл.

python predict.py


На выходе создается файл с ответами: submission_seed_42.csv

🔬 Воспроизводимость и параметры модели

Seed: зафиксирован на значении SEED = 42 (в train.py и predict.py).

Модель: Градиентный бустинг CatBoostClassifier (автоматически обрабатывает категориальные признаки и пропуски).

Гиперпараметры:

iterations = 1000
learning_rate = 0.05
depth = 6
eval_metric = 'F1'
random_seed = SEED
early_stopping_rounds = 50


🔍 Проверка результата

После генерации файла с предсказаниями рекомендуется проверить его корректность с помощью короткой команды в терминале:

python -c "
import pandas as pd
sub = pd.read_csv('submission_seed_42.csv')
print(sub.head())
print('Rows:', len(sub))
print('Columns:', sub.columns.tolist())
print('Unique customer_id:', sub['customer_id'].nunique())
print('Values:', sub['accepted'].unique())
"


Файл должен содержать 1000 строк, столбцы customer_id и accepted, а также бинарные значения 0 / 1.
